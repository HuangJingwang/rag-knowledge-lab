# 支付结果查询与回调重试

查询接口按支付流水号返回处理中、成功或失败，只有成功时才推动订单进入已支付状态。

回调失败后的重试规则只适用于已启用幂等校验的接口。重复查询和回调不得重复发货。

维护说明：本文件为人工编写的简化 OKF 教学示例。
复核日期是本演示设置的维护时间，不是原文章给出的业务期限。
